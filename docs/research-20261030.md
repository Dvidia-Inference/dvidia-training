# DVIDIA simulation research: 30 October 2026

## A testable local scene

The OpenUSD workstation v0.1 parses one original rigid cube, tabletop and explicit mass, centred inertia, gravity and friction with the real USD SDK. Native MuJoCo preserves a pinned PiPER arm model. All **45/45 passive physics checks pass**: 27 drops, nine slides and nine missing-effect controls. This is not a learned manipulation success rate.

[Recorded 3D workstation](https://dvidia-robot-simulation-lab.static.hf.space/usd-workstation/v01/index.html) · [Research paper](https://research.dvidia.org/papers/openusd-workstation-v01/) · [GitHub release](https://github.com/Dvidia-Inference/dvidia-training/releases/tag/usd-workstation-v0.1) · [Hugging Face dataset](https://huggingface.co/datasets/Dvidia/usd-workstation-v01) · [Benchmark and independent audit](../benchmarks/usd-workstation-v01/README.md)

The release ZIP runs as a recorded viewer after extraction with `python -m http.server 8000`. Open `http://127.0.0.1:8000/`. To run fresh native physics, use the immutable source tag below. The main branch continues to host the base training pipeline; this simulator release has its own source snapshot.

```sh
git clone --branch usd-workstation-v0.1 --depth 1 https://github.com/Dvidia-Inference/dvidia-training.git dvidia-usd
cd dvidia-usd
python3.12 -m venv .venv
. .venv/bin/activate
python -m pip install 'pip==26.2.2'
python -m pip install --resume-retries 4 '.[usd]'
dvidia-scene validate examples/usd-workstation-v01/recipe.json
dvidia-robot-sim fetch piper --output ./robot-assets
dvidia-scene build examples/usd-workstation-v01/recipe.json --assets ./robot-assets --output ./scene-check
```

[Full native benchmark commands and supported USD contract](https://github.com/Dvidia-Inference/dvidia-training/blob/usd-workstation-v0.1/docs/usd-workstation-v01.md). A separate [installed-package smoke](../benchmarks/usd-workstation-v01/clean-install-smoke.json) validates isolated installed modules, CLI build/inspection and 1,200 passive native ticks outside the checkout. Hash verification remained enabled throughout; interrupted downloads required bounded resumption. That smoke reused verified local robot assets, so fresh asset download and other host platforms are not qualified by it.

No dedicated GPU was used for headless native physics. Browser replay needs WebGL2. Minimum RAM, other operating systems, hard real-time behavior and calibrated real-object contacts remain unqualified. This bridge rejects unsupported USD composition and articulations; it cannot import arbitrary SimReady assets.

## Bounded waiting, with unknowns preserved

The v0.4 authored acquisition supervisor waits at most 200 ms, then latches progress or explicitly aborts. The frozen learned prediction is advisory; no new motor weights were trained. Of 512 scheduled confirmation attempts, 508 are scored and four are explicitly unknown after interruption. Only the primary scheduled analysis imputes those unknowns as failures. Strict completions per 128 scheduled attempts are 42 bounded, 32 learned clock, 44 fixed and 41 teacher. Both paired comparisons are inconclusive.

[Research and all scheduled outcomes](https://research.dvidia.org/papers/bounded-grip-waiting-v04/) · [GitHub compact release and source tag](https://github.com/Dvidia-Inference/dvidia-training/releases/tag/piper-grip-wait-v0.4-recovery) · [Hugging Face compact dataset](https://huggingface.co/datasets/Dvidia/piper-grip-wait-recovery-v04) · [Local compact audit lineage](../benchmarks/piper-grip-wait-v04/recovery-20261030/README.md)

The full raw native archive remains local. Compact summaries bind its SHA256 and preserve every scheduled case, both analyses, 556 complete audit identities and interruption manifests. Frequent retention and critical-contact failures remain. These studies do not establish human-video motor learning, shoe skills, cross-arm installation or physical robot readiness.
