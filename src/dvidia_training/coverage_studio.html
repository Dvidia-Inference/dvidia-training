Coverage of the operating envelope

Every skill starts with a simulation benchmark

    This is a benchmark specification. Qualification requires an executable task environment, a frozen protocol and artifact-bound results for every attempted trial. A skill without a suitable environment stays blocked.

    Recognize contributions that close a gap

    Make each recording request explain why it matters. Return a review receipt showing whether the attempt was accepted, needs correction, or adds a useful variation.

    • Recognize approved independent sessions and underrepresented conditions.
    • Recognize honest failures, recovery attempts and useful label corrections.
    • Show opt-in dataset credit and team coverage milestones.
    • For future funded campaigns, state the budget and acceptance terms before anyone records.

    Incentive design proposal. This prototype issues no rewards, points, payments or public contributor credit. More cuts from one source do not create independent evidence.

    Define and revise the collection plan

    Saving a changed plan creates a new revision. Earlier evidence keeps its review history and needs review against the new plan before it can satisfy targets.

    Import or inspect a coverage-plan JSON

    This companion plan is separate from the footage manifest. Importing review metadata does not validate the underlying recording, permissions or reviewer judgment.
