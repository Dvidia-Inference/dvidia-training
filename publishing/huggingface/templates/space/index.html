Train on your own computer or server. This Space shows fixed, published measurements and a recorded simulation replay. It offers no hosted training or uploads. The current pilot establishes neither a hardware skill nor a bridge from raw human video to robot actions.

01

A local, inspectable pipeline

The tool checks actual videos and connected source groups, freezes training/development/test splits, fits a small model on a CPU, and exports learned weights with held-out measurements and integrity hashes.

The base learner needs Python 3.12+, NumPy, and FFmpeg with ffprobe. It requires no GPU, CUDA, account, or API key. Training runs offline by default; installing software and downloading public data are separate steps.

Visual fitting and movement fitting have different inputs. Footage trains the visual predictor. The optional movement branch requires compatible, validated numerical action supervision and a task adapter.

03

A learned movement candidate

A separate native simulation pilot fits a six-joint delta head from aligned simulator state and authored joint targets. The training set contains 4,029 numerical labels across seven recordings; development uses two recordings, and one recording is held out.

05

Run the tool locally

Install Python 3.12+ and FFmpeg first, then use these macOS/Linux commands. The local studio opens at 127.0.0.1:8270 on your own machine.

git clone https://github.com/Dvidia-Inference/dvidia-training.git
cd dvidia-training
python3.12 -m venv .venv
.venv/bin/python -m pip install .
.venv/bin/dvidia-training-studio --directory runs/studio

To reproduce the synthetic visual path, create a small example, train it, and inspect its export. Each run requires a fresh output directory.

.venv/bin/dvidia-train example --clips 10 --output examples/visual-demo
.venv/bin/dvidia-train run examples/visual-demo --output runs/visual-demo
.venv/bin/dvidia-train inspect runs/visual-demo

The optional native arm branch adds MuJoCo and the capsule tools through .venv/bin/python -m pip install ".[arm]". Its task contract and closed-loop qualification are separate from visual fitting.

07

What remains open

The long-term aim is installable robot skills. This research alpha is a smaller, inspectable step toward that aim.

  • Visual prediction error does not establish task success, calibrated geometry, or robot competence.
  • No human-video action bridge, shoe organization policy, or demonstration sufficiency threshold has been established.
  • The movement evidence covers one held-out synthetic recording and its exact simulation scene. Independent scene generalization remains unmeasured.
  • Task phases, contact/gripper logic, and recovery remain authored. Hardware sensing, calibration, actuation, and physical qualification remain separate work.
